🌐 Modelo de Red Abierta

¿Cuándo se usa?

Para sistemas con una fuente infinita de clientes. Llegan, se les sirve y se van.

Ejemplos: Servidores web, APIs públicas, sistemas de streaming.

La receta (el algoritmo de resolución)

  1. 1
    Calcular utilizaciones (Uᵢ):
    Uᵢ = λ₀ × Dᵢ
  2. 2
    Calcular tiempos de respuesta por recurso (Rᵢ):
    Rᵢ = Sᵢ / (1 - Uᵢ)

    ¡Rᵢ se dispara cuando Uᵢ se acerca al 100%!

  3. 3
    Calcular tiempo de respuesta total (R):
    R = Σ (Vᵢ × Rᵢ)

Esta es la herramienta para el Caso Práctico 1: El Dilema de la Actualización.

🔄 Modelo de Red Cerrada

¿Cuándo se usa?

Para sistemas con una población finita y constante de clientes (N) que circulan sin salir.

Ejemplos: Sistemas de terminales, procesos batch con hilos fijos.

El atajo del administrador (límites)

En lugar del algoritmo MVA completo, calculamos el punto de colapso del sistema.

Concepto clave: el punto de saturación (N*)

Es el "número mágico" de usuarios. Por encima de él, el sistema colapsa.

N* = (ΣDᵢ + Z) / Dₑ

Donde Dₑ es la demanda del cuello de botella.

Esta es la herramienta para el Caso Práctico 2: La Saturación.
