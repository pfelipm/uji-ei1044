El Universo de los Objetos

El concepto que lo cambia TODO en PowerShell

¿Qué es un Objeto?

Imagina un objeto del mundo real, como un coche. No es solo un trozo de texto; es una entidad con características y acciones que puede realizar.

Características (Propiedades)

Son los datos que describen al objeto.

  • Color: "Rojo"
  • Modelo: "Seat Ibiza"
  • Año: 2023
  • VelocidadActual: 50

Acciones (Métodos)

Son las "cosas" que el objeto sabe hacer.

  • Arrancar()
  • Acelerar()
  • Frenar()
  • Apagar()

La Regla de Oro: En PowerShell, el resultado de un comando NO es texto, es una colección de objetos, cada uno con sus propias propiedades y métodos.

La Llave Maestra: Get-Member

Si los comandos devuelven objetos, ¿cómo sabemos qué propiedades y métodos tienen? Usamos el cmdlet más importante para aprender:

Get-Process | Get-Member # O con su alias: gps | gm

Get-Member (o gm) actúa como un "escáner" que nos dice la anatomía de cualquier objeto que le pasemos por la tubería.

Ejemplo de salida de Get-Member para un proceso:

TypeName: System.Diagnostics.Process

Name        MemberType     Definition
----        ----------     ----------
Kill        Method         void Kill()
Refresh     Method         void Refresh()
...
CPU         Property       double CPU {get;}
Id          Property       int Id {get;}
Name        Property       string Name {get;}
WS          Property       long WS {get;}

La Tubería (|): Una Cadena de Montaje

La tubería es el mecanismo que nos permite pasar la colección de objetos de un cmdlet a otro. Cada cmdlet en la cadena realiza una operación sobre los objetos que recibe y pasa el resultado al siguiente.

Get-Process

Produce cientos de objetos "Proceso"

|

Where-Object

Filtra y deja pasar solo los objetos que cumplen una condición

|

Sort-Object

Recibe los objetos filtrados y los reordena por una propiedad

|

Select-Object

Recibe los objetos ordenados y selecciona solo las propiedades que queremos ver

El Kit de Herramientas del SysAdmin

Filtrar: Where-Object

Para quedarte solo con los objetos que cumplen una condición.

# Procesos cuyo nombre empieza por "code" Get-Process | Where-Object { $_.Name -like "code*" }

Ordenar: Sort-Object

Para ordenar la colección de objetos según una de sus propiedades.

# Ordenar por uso de CPU de mayor a menor Get-Process | Sort-Object -Property CPU -Descending

Seleccionar: Select-Object

Para elegir qué propiedades del objeto quieres ver o para coger los N primeros/últimos.

# Coger los 5 primeros y mostrar solo su nombre y memoria ... | Select-Object -First 5 -Property Name, WS
