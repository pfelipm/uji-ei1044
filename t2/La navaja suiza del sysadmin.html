Introducción a PowerShell 7

¿Para qué sirve? El poder de la automatización

PowerShell no es solo una línea de comandos; es un framework de automatización diseñado para que los administradores de sistemas (SysAdmins) y desarrolladores (DevOps) puedan gestionar infraestructuras complejas y automatizar tareas repetitivas a escala.

Automatización de tareas

  • Crear 500 usuarios a partir de un CSV.
  • Reiniciar un servicio en 100 servidores a la vez.
  • Limpiar logs de más de 90 días.

Gestión de infraestructura

  • Desplegar y configurar Máquinas Virtuales en Azure.
  • Administrar usuarios y políticas en Microsoft 365.
  • Generar informes de estado de toda tu red.

Su lugar en el ecosistema de herramientas

Cada entorno tiene sus herramientas predilectas. PowerShell es el rey indiscutible en el ecosistema Microsoft, pero es importante conocer las alternativas.

El salto conceptual: de texto a objetos

Esta es la diferencia FUNDAMENTAL. Mientras las shells tradicionales como Bash manipulan texto plano, PowerShell trabaja con objetos de datos estructurados. Esto lo cambia todo.

Shells Tradicionales (Bash): Mundo de Texto

Los comandos devuelven líneas de texto. Para usar esa salida, debes usar otras herramientas (grep, awk) para "cortar" y "pegar" el texto que necesitas. Es flexible pero frágil.

PowerShell: Mundo de Objetos

Los cmdlets devuelven objetos con propiedades. Accedes a los datos directamente por su nombre (.Name, .Id), sin interpretar texto. Es robusto, predecible y potente.

# Objetivo: Obtener el ID del proceso 'code' # 1. ps aux: Devuelve una tabla de TEXTO. # 2. grep: Filtra LÍNEAS de texto. # 3. awk: Extrae la 2ª COLUMNA de texto. ps aux | grep 'code' | awk '{print $2}'
# Objetivo: Obtener el ID del proceso 'code' # 1. Get-Process: Devuelve OBJETOS. # 2. Where-Object: Filtra OBJETOS por propiedad. # 3. Select-Object: Selecciona una PROPIEDAD. Get-Process | Where-Object Name -eq 'code' | Select-Object Id

¿Cómo lo uso?

Terminal local

Instálalo directamente en tu sistema operativo y ejecútalo desde tu terminal preferida.

Azure Cloud Shell (¡Recomendado!)

Accede a una terminal de PowerShell completa desde cualquier navegador web en shell.azure.com. No requiere instalación.

Visual Studio Code

El editor estándar de la industria para escribir, depurar y ejecutar scripts de PowerShell, gracias a su extensión oficial.

Fundamentos: tu caja de herramientas

Cmdlets: los comandos (verbo-nombre)

Los comandos en PowerShell tienen una estructura predecible y fácil de recordar.

Get-Process # Obtener información Set-Content # Modificar información Start-Service # Realizar una acción New-Item # Crear algo nuevo

Alias: los atajos

Para ser más rápido, PowerShell usa alias que te resultarán familiares si vienes de Linux o CMD.

ls, dir -> Get-ChildItem ps -> Get-Process cat -> Get-Content kill -> Stop-Process

Get-Help: tu mejor amigo

¿No sabes cómo funciona un comando? Get-Help es la clave para ser autónomo. ¡Úsalo siempre!

# Ayuda completa de un comando Get-Help Get-Process -Full # Ver solo los ejemplos prácticos Get-Help Get-Process -Examples
