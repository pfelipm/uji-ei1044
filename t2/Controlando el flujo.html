Controlando el Flujo

Tomando Decisiones y Repitiendo Tareas

Tomando Decisiones: if, elseif, else

Las estructuras condicionales permiten que tu script ejecute diferentes bloques de código según si una condición es verdadera ($true) o falsa ($false).

$servicio = Get-Service -Name "spooler" -ErrorAction SilentlyContinue if ($servicio -eq $null) { # Si el servicio NO existe... Write-Warning "El servicio de impresión no está instalado." } elseif ($servicio.Status -eq "Running") { # Si existe y está en ejecución... Write-Host "El servicio de impresión está activo." -ForegroundColor Green } else { # Si existe pero no está activo... Write-Host "Servicio detenido. Iniciando..." -ForegroundColor Yellow Start-Service -Name "spooler" }

La alternativa: switch

Para múltiples elseif, la estructura switch puede ser más limpia. Compara un valor contra una lista de posibles coincidencias.

Repitiendo Tareas: Los Bucles

Los bucles son la base de la automatización. Permiten ejecutar un bloque de código una y otra vez hasta que se cumpla una condición.

Bucle foreach

El más usado en PowerShell. Itera sobre cada elemento de una colección (un array).

$servidores = "srv-web01", "srv-db01", "srv-dc01" foreach ($servidor in $servidores) { # Este código se repite para cada servidor. Write-Host "Procesando $servidor..." }

Bucle for

El bucle clásico. Se ejecuta un número específico de veces usando un contador.

for ($i = 1; $i -le 3; $i++) { # Este código se repite 3 veces. Write-Host "Creando usuario temporal n. $i" }

Bucle while

Se repite mientras una condición sea verdadera. La condición se comprueba al principio.

$contador = 3 while ($contador -gt 0) { Write-Host "Despegue en $contador..." $contador-- # Decrementamos el contador. Start-Sleep -Seconds 1 } Write-Host "¡Despegue!"

Bucle do-while

Similar a while, pero garantiza que el código se ejecuta al menos una vez, ya que la condición se comprueba al final.

$entrada = "" do { $entrada = Read-Host "Escribe 'salir' para terminar" } while ($entrada -ne "salir") Write-Host "¡Adiós!"
