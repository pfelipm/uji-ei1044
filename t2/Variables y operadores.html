Variables y Operadores

Guardando y Manipulando Datos

Variables: Las Cajas para tus Datos

Una variable es un contenedor con un nombre que guarda información. En PowerShell, los nombres de las variables siempre empiezan con el símbolo $.

# Asignamos el texto "Pablo" a la variable $nombre $nombre = "Pablo" # Asignamos el número 12 a la variable $alumnos $alumnos = 12 # Mostramos el contenido de la variable Write-Output "Hola, $nombre. Hoy sois $alumnos alumnos."

Tipado Dinámico: Por defecto, no necesitas declarar el tipo de una variable. PowerShell lo infiere. Puedes guardar un número y luego un texto en la misma variable.

Tipado Estricto (Opcional): Si quieres forzar un tipo, puedes hacerlo: [int]$edad = 40. ¡Ahora $edad solo aceptará números enteros!

Comillas: Literal vs. Expansión

Uno de los detalles más importantes en administración de sistemas es cómo trata PowerShell las cadenas de texto:

Comillas Simples '...' (Literal)

No evalúa nada en su interior. El texto se conserva exactamente como está escrito, carácter a carácter.

# Muestra literalmente: Hola $nombre Write-Output 'Hola $nombre'

Comillas Dobles "..." (Expansión)

Expande variables y subexpresiones. Para acceder a propiedades de objetos dentro de un string, usa siempre $($obj.Prop).

# Expande variables y propiedades de objeto $proc = Get-Process -Id $PID Write-Output "Proceso actual: $($proc.ProcessName) (PID: $($proc.Id))"

Operadores de Comparación

En lugar de los símbolos habituales (==, !=, >, <), PowerShell utiliza operadores con guion que son más legibles. Por defecto, no distinguen entre mayúsculas y minúsculas.

-eq (equal) Igual a
-ne (not equal) No igual a
-gt (greater than) Mayor que
-ge (greater or equal) Mayor o igual que
-lt (less than) Menor que
-le (less or equal) Menor o igual que
-like Coincide con un patrón (*, ?)
-contains La colección contiene un valor

Sensible a Mayúsculas: Si necesitas que la comparación distinga mayúsculas de minúsculas, añade una 'c' al principio: -ceq, -cgt, -clike, etc.

¡Trampa clásica de SysAdmin! La regla de oro del $null

En PowerShell, si colocas una colección o array a la izquierda del operador de comparación ($array -eq $null), PowerShell no comprueba si el array es nulo, sino que filtra los elementos que sean nulos dentro de la colección.

# ❌ PELIGRO: Si $usuarios es un array, devolverá elementos nulos, no un booleano $true/$false if ($usuarios -eq $null) { ... } # ✅ CORRECTO: Coloca siempre $null a la IZQUIERDA para evaluar el objeto en su conjunto if ($null -eq $usuarios) { Write-Host "No hay datos recibidos" }

Operadores Aritméticos y Lógicos

Funcionan de manera muy similar a otros lenguajes de programación, permitiéndote realizar cálculos y combinar condiciones.

Aritméticos

  • + Suma (y concatena cadenas)
  • - Resta
  • * Multiplicación (y repite cadenas)
  • / División
  • % Módulo (resto de la división)

Lógicos

  • -and Y Lógico (ambas deben ser ciertas)
  • -or O Lógico (al menos una debe ser cierta)
  • -not o ! NO Lógico (invierte el valor)
# Ejemplo combinado $edad = 30 $nombre = "Adolfo" # ¿Es Adolfo y tiene 30 años o más? ($nombre -eq "Adolfo") -and ($edad -ge 30) # Devuelve: True
