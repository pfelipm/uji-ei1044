Ampliando PowerShell y Manejando Datos

Módulos: El Supermercado de Funcionalidades

Un módulo es un paquete que contiene nuevos cmdlets y funciones para ampliar las capacidades de PowerShell. La PowerShell Gallery es el repositorio oficial donde la comunidad y Microsoft publican miles de módulos.

# 1. BUSCAR un módulo en la galería Find-Module -Name "PSScriptAnalyzer" # 2. INSTALAR un módulo desde la galería (requiere permisos de admin) Install-Module -Name "PSScriptAnalyzer" -Scope CurrentUser # 3. VER los nuevos comandos que ha añadido el módulo Get-Command -Module "PSScriptAnalyzer" # 4. USAR uno de los nuevos comandos Invoke-ScriptAnalyzer -Path "./MiScript.ps1"

Ficheros: La Persistencia de Datos

Un script a menudo necesita leer datos de un fichero o guardar sus resultados. PowerShell tiene cmdlets nativos para manejar los formatos más comunes de forma muy sencilla.

Ficheros de Texto (.txt, .log)

# Leer el contenido de un fichero línea a línea $lineas = Get-Content -Path "./logs.txt" # Sobrescribir un fichero con nuevo contenido Set-Content -Path "./informe.txt" -Value "Este es el informe." # Añadir una nueva línea al final de un fichero Add-Content -Path "./informe.txt" -Value "Fin del informe."

CSV (.csv): El Superpoder de PowerShell

PowerShell trata los ficheros CSV como si fueran bases de datos. Automáticamente convierte las filas en objetos, ¡lo que te permite usar Where-Object, Sort-Object, etc.!

# Contenido de 'usuarios.csv': # Nombre,Departamento # Pablo,LSI # Adolfo,LSI # Importar el CSV y convertirlo en una colección de objetos $usuarios = Import-Csv -Path "./usuarios.csv" $usuarios[0].Nombre # Devuelve "Pablo" # Exportar una colección de objetos a un fichero CSV Get-Process | Select-Object Name,Id | Export-Csv -Path "./procesos.csv" -NoTypeInformation

JSON (.json): El Lenguaje de la Web

De forma similar a los CSV, PowerShell puede convertir objetos a y desde el formato JSON, el estándar para la comunicación con APIs web.

$procesos = Get-Process | Select-Object Name, Id -First 2 # Convertir objetos de PowerShell a una cadena de texto en formato JSON $json = $procesos | ConvertTo-Json # Convertir una cadena JSON de vuelta a objetos de PowerShell $objetos = $json | ConvertFrom-Json
