Colecciones de Datos

Organizando Múltiples Elementos

Arrays: Listas Ordenadas

Un array es la estructura más básica para guardar una colección de elementos. Es simplemente una lista donde cada elemento tiene una posición (un índice), empezando por el 0.

# Creación de un array separando elementos por comas $servidores = "srv-dc01", "srv-web01", "srv-db01" # Acceder al primer elemento (índice 0) $servidores[0] # Devuelve: srv-dc01 # Acceder al último elemento $servidores[-1] # Devuelve: srv-db01 # Contar cuántos elementos hay $servidores.Count # Devuelve: 3 # Añadir un nuevo elemento al array $servidores += "srv-backup01"

Otras formas de crear arrays:

  • $vacio = @() - Para crear un array vacío.
  • $numeros = 1..5 - Con el operador de rango.

Hashtables: Diccionarios Clave-Valor

Una hashtable (o tabla hash) es una colección que no usa posiciones, sino claves (nombres) para guardar y recuperar valores. Es ideal para almacenar datos estructurados.

# Creación de una hashtable con la sintaxis @{ Clave = Valor; ... } $usuario = @{ Nombre = "Pablo" Rol = "Docente" ID = 1044 Activo = $true } # Acceder a un valor por su clave (notación de punto) $usuario.Rol # Devuelve: Docente # Acceder a un valor con la clave como string $usuario['ID'] # Devuelve: 1044 # Añadir una nueva pareja clave-valor $usuario.Departamento = "LSI"

¿Array o Hashtable?

  • Usa un Array cuando el orden de los elementos es importante y los accedes por su posición.
  • Usa una Hashtable cuando necesites buscar valores por un nombre específico (su clave) y el orden no sea relevante.
