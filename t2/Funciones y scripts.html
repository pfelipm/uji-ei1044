Funciones y Scripts

Creando tus Propias Herramientas

De Usuario a Creador

Escribir comandos uno a uno está bien para explorar, pero el verdadero poder de PowerShell se desata cuando empaquetas tu lógica para poder reutilizarla. Aquí es donde entran las funciones y los scripts.

Funciones

Bloques de código con nombre que viven en la memoria de la sesión. Se definen interactivamente en la consola (uso temporal) o se guardan dentro de scripts (reutilizable).

Scripts (.ps1)

Ficheros de texto que contienen comandos y funciones. Son tus herramientas. Los guardas y los ejecutas para realizar tareas complejas.

Anatomía de una Función

Una función agrupa una serie de comandos bajo un nombre. Su estructura es simple y clara.

function Get-Saludo { # El bloque param() define los "argumentos" o "parámetros" de entrada. param ( [string]$Nombre ) # El cuerpo de la función contiene la lógica. Write-Output "¡Hola, $Nombre! Bienvenido a PowerShell." }

¿Cómo se usa? Una vez definida la función en tu sesión, simplemente la llamas por su nombre y le pasas los parámetros.

Get-Saludo -Nombre "Pablo"

El Bloque param(): Un Mecanismo Universal

Este es un concepto clave: el bloque param() se usa de la misma forma para definir los parámetros de una función y para convertir un script entero en un cmdlet.

  • Dentro de una función, define sus argumentos de entrada.
  • Al principio de un script, lo convierte en una herramienta de línea de comandos profesional, permitiéndote llamarlo con parámetros con nombre (ej: -Parametro Valor).

El Script: Tu Herramienta Reutilizable

Un script no es más que un fichero de texto plano, guardado con la extensión .ps1, que contiene el código que quieres ejecutar.

Contenido de MiScript.ps1:

# Fichero: MiScript.ps1 [CmdletBinding()] param ( [Parameter(Mandatory=$true)] # Hacemos que -Directorio sea obligatorio. [string]$Directorio ) # La lógica del script: listar los ficheros del directorio indicado. Write-Output "Mostrando ficheros en: $Directorio" Get-ChildItem -Path $Directorio

¿Cómo se gestiona? Hay dos formas principales de usar un script:

1. Ejecutarlo directamente: Realiza las acciones del script.

./MiScript.ps1 -Directorio "/etc"

2. "Dot Sourcing": Carga sus funciones en memoria para usarlas tú, sin ejecutar el resto del script.

. ./MiScript.ps1
